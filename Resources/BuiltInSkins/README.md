# 内置示例卡面

把图片放进这个目录，打包时（`scripts/package_app.sh`）会复制进 App，作为内置示例显示在皮肤网格最前面，排在 8 个渐变示例之前。

- 格式：PNG / JPEG / HEIC，建议 **1536×969**（Wallet 卡面尺寸），否则写入时会被裁切。
- 皮肤名称取自文件名（不含扩展名），按文件名自然排序；可以用 `1 富士山.png`、`2 樱花.png` 这样的前缀控制顺序。
- **文件名就是皮肤的身份**：改名会被当成新皮肤，用户卡片上的“当前选用”标记会消失。
- 不要使用任何银行、发卡机构或卡组织的标识（见免责声明）。

这个 README 不会被当成皮肤（只加载图片文件）。
